Learning untuk Industri

Mahasiswa memahami cara kerja machine learning secara umum, membedakan jenis masalah industri yang cocok untuk AI, serta menyiapkan logika dasar untuk analisis data dan evaluasi solusi.

Teori + Praktik 100 menit CPMK: C2, C3

Tujuan Pembelajaran

Setelah mengikuti sesi 2, mahasiswa diharapkan mampu:

  1. Membedakan tiga paradigma utama machine learning: supervised, unsupervised, dan reinforcement learning.
  2. Menjelaskan alur dasar penyelesaian masalah AI pada data industri: input, pembersihan, model, evaluasi, dan keputusan.
  3. Menentukan tipe data dan bentuk masalah yang relevan untuk prediksi, klasifikasi, dan segmentasi.
  4. Memahami indikator performa model dan interpretasi hasil tanpa mengandalkan pemahaman coding.
💡

Prasyarat: Mahasiswa dapat membaca data umum, mengenal konsep variabel, dan memahami bahwa AI untuk industri adalah alat bantu pengambilan keputusan, bukan pengganti pengalaman operasional.

1. Tiga Paradigma Machine Learning

Dunia industri sering menemui permasalahan yang tidak dapat diselesaikan hanya dengan aturan if-else. Machine learning menjadi pendekatan yang relevan ketika data historis berlimpah dan hubungan pola dapat dipelajari.

Supervised Learning

Model belajar dari data yang memiliki label atau target. Contohnya: prediksi kualitas produk, forecasting demand, klasifikasi cacat barang.

Unsupervised Learning

Model melakukan pengelompokan atau pengurangan dimensi pada data tanpa label. Contohnya: segmentasi pelanggan, grouping mesin berdasarkan pola konsumsi energi.

Reinforcement Learning

Agent belajar melalui trial and error untuk memaksimalkan reward. Contohnya: kontrol sistem otomatis, jadwal produksi adaptif, routing kendaraan.

2. Proses Menyelesaikan Masalah Industri dengan AI

Langkah Aktivitas Hasil
1. Identifikasi masalah Menentukan target keputusan: kualitas, stok, risiko outage, demand, atau inspeksi. Definisi KPI dan target bisnis.
2. Pengumpulan data Data dari MES, ERP, sensor, insan/QA, penjualan, atau sistem logistik. Dataset awal yang siap dianalisis.
3. Pembersihan data Memeriksa data kosong, duplikasi, outlier, format tanggal, dan konsistensi. Data yang siap diproses.
4. Pemodelan Memilih teknik sesuai jenis masalah dan data. Model awal dan output prediksi.
5. Evaluasi Mengukur akurasi, eror, interpretasi hasil, serta trade-off manfaat dan biaya. Keputusan apakah model siap dipakai.

3. Praktik Sesi

Praktik pada sesi ini dilakukan secara observasional dan berorientasi pada kasus. Mahasiswa tidak dituntut menulis kode, tetapi diminta membaca data, membahas karakteristik masalah, dan menyusun hipotesis solusi.

Aktivitas:

  • Identifikasi satu masalah industri di lingkungan kampus atau pabrik demonstrasi.
  • Tentukan apakah masalah termasuk klasifikasi, prediksi, optimasi, atau segmentasi.
  • Buat daftar data yang perlu dikumpulkan untuk mendukung solusi.
  • Diskusikan KPI yang akan dijadikan indikator keberhasilan.

4. Evaluasi Sesi

Penilaian sesi 2 akan berfokus pada kemampuan mahasiswa menunjukkan pemahaman terhadap:

  • Perbedaan tipe masalah berlabel dan tidak berlabel.
  • Hubungan antara data, model, dan keputusan bisnis.
  • Penentuan target solusi AI yang sesuai dengan kebutuhan industri.
