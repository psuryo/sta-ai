Cell 9 — Feature Engineering untuk Random Forest

In [9] Feature Engineering — Fitur Kalender & Lag 
def buat_fitur(series):
    """Buat fitur time series untuk model ML."""
    df_f = pd.DataFrame({'volume': series})
    df_f.index = pd.to_datetime(df_f.index)

    # Fitur kalender
    df_f['bulan']       = df_f.index.month
    df_f['kuartal']     = df_f.index.quarter
    df_f['bulan_sin']   = np.sin(2 * np.pi * df_f['bulan'] / 12)
    df_f['bulan_cos']   = np.cos(2 * np.pi * df_f['bulan'] / 12)
    df_f['is_lebaran']  = df_f['bulan'].isin([4, 5]).astype(int)

    # Fitur lag (nilai historis)
    df_f['lag_1']  = df_f['volume'].shift(1)   # bulan lalu
    df_f['lag_2']  = df_f['volume'].shift(2)   # 2 bulan lalu
    df_f['lag_3']  = df_f['volume'].shift(3)   # 3 bulan lalu
    df_f['lag_12'] = df_f['volume'].shift(12)  # setahun lalu

    # Fitur rolling
    df_f['ma_3']   = df_f['volume'].shift(1).rolling(3).mean()
    df_f['ma_6']   = df_f['volume'].shift(1).rolling(6).mean()

    return df_f.dropna()

# Buat fitur dari seluruh data Surabaya

4. Evaluasi & Perbandingan Model

Kita gunakan tiga metrik evaluasi khusus untuk regresi time series. Memahami perbedaannya penting — setiap metrik menjawab pertanyaan yang berbeda.

MAPE
mean(|aktual−pred| / aktual)
Mean Absolute Percentage Error — error dalam persen. Mudah dikomunikasikan: "prediksi kami rata-rata meleset 8%." Sensitif terhadap nilai aktual mendekati nol.
MAE
mean(|aktual − pred|)
Mean Absolute Error — error dalam satuan asli (unit). Mudah diinterpretasi: "rata-rata meleset 230 unit/bulan." Tidak terlalu sensitif terhadap outlier.
RMSE
√mean((aktual − pred)²)
Root Mean Squared Error — seperti MAE tapi menghukum error besar lebih berat. Lebih relevan jika error besar sangat merugikan (mis. kekurangan stok saat Lebaran).

Cell 11 — Hitung Semua Metrik

In [11] Evaluasi — MAPE, MAE, RMSE per Model 
def hitung_metrik(aktual, prediksi, nama):
    mae  = mean_absolute_error(aktual, prediksi)
    rmse = np.sqrt(mean_squared_error(aktual, prediksi))
    mape = np.mean(np.abs((aktual - prediksi) / aktual)) * 100
    return {'Model': nama, 'MAPE (%)': round(mape, 2),
            'MAE (unit)': round(mae, 0), 'RMSE (unit)': round(rmse, 0)}

aktual = hasil['aktual'].values

rows = [
    hitung_metrik(aktual, hasil['MA_3bln'].values,    'Moving Average 3 bln'),
    hitung_metrik(aktual, hasil['MA_12bln'].values,   'Moving Average 12 bln'),
    hitung_metrik(aktual, hasil['HoltWinters'].values,'Holt-Winters ES'),
    hitung_metrik(aktual, hasil['RandomForest'].values,'Random Forest ML'),
]
tabel = pd.DataFrame(rows).set_index('Model')
print("=== Perbandingan Akurasi Model (6 bulan uji) ===\n")
print(tabel.to_string())

print("\n⭐ Model terbaik (MAPE terendah):",
      tabel['MAPE (%)'].idxmin(),
      f"→ MAPE = {tabel['MAPE (%)'].min():.2f}%")

5. Simulasi Keputusan Stok

Ini adalah bagian yang paling langsung relevan untuk seorang insinyur industri: bagaimana akurasi model forecasting diterjemahkan menjadi keputusan operasional yang nyata — khususnya reorder point dan safety stock.

Dari Prediksi ke Keputusan Reorder

Formula Konvensional
ROP = d̄ × L + SS
SS = Z × σ × √L
d̄ = rata-rata demand
L = lead time (bulan)
σ = standar deviasi demand
Z = Z-score service level
Dengan Prediksi AI
ROP = pred × L + SSAI
SSAI = Z × MAPE × pred × √L
pred = demand yang diprediksi model
SSAI dinamis sesuai ketidakpastian
MAPE mengukur ketidakpastian model

import scipy.stats as stats

# Parameter operasional
lead_time     = 2      # bulan (waktu dari order ke terima)
service_level = 0.95   # target: 95% tidak stockout
Z = stats.norm.ppf(service_level)  # Z = 1.645

print(f"Parameter: Lead Time = {lead_time} bln | Service Level = {service_level*100:.0f}% | Z = {Z:.3f}")

Ringkasan Pertemuan Ini

  • Data time series harus dieksplorasi dulu untuk memahami pola tren, musiman, dan anomali sebelum membangun model — dekomposisi seasonal_decompose() membantu memvisualisasikan ketiga komponen ini
  • Train-test split untuk time series harus temporal, bukan acak — data terbaru dipakai untuk pengujian agar tidak "bocor" informasi masa depan ke model
  • Moving Average adalah baseline yang baik, Holt-Winters menangkap tren dan musiman dengan baik, Random Forest unggul ketika banyak fitur kontekstual (Lebaran, lag historis) tersedia
  • MAPE adalah metrik paling komunikatif untuk demand forecasting — langsung terjemahkan ke unit produk dan biaya untuk percakapan dengan manajemen
  • Prediksi yang lebih akurat (MAPE lebih rendah) memungkinkan safety stock yang lebih kecil tanpa menurunkan service level — ini adalah nilai bisnis nyata dari investasi di forecasting AI
  • Feature engineering (fitur lag, musiman, kalender) adalah kunci keunggulan Random Forest untuk data time series industri — bukan kompleksitas model itu sendiri
