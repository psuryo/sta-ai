Deep Learning &
Neural Network

Dari satu neuron buatan hingga jaringan berlapis ratusan — bagaimana neural network belajar dari data, apa yang membuat deep learning berbeda dari ML klasik, dan kapan tepatnya kamu harus menggunakannya.

Teori 100 menit CPMK: C1, C3

Tujuan Pembelajaran

Setelah mengikuti pertemuan ini, mahasiswa diharapkan mampu:

  1. Menjelaskan cara kerja neuron buatan dan bagaimana lapisan-lapisan membentuk jaringan yang mampu belajar
  2. Menerangkan mekanisme training: forward pass, fungsi loss, backpropagation, dan gradient descent
  3. Membedakan arsitektur ANN, CNN, dan RNN serta mengidentifikasi use case yang tepat untuk masing-masing
  4. Mengenal ekosistem TensorFlow / Keras dan memahami konsep model Sequential dan Functional API
  5. Memutuskan kapan deep learning lebih tepat daripada ML klasik berdasarkan karakteristik data dan masalah
🔗

Fondasi dari P-03: Di P-03 kamu membangun Random Forest dan Logistic Regression — keduanya bekerja dengan fitur yang sudah kamu definisikan secara manual. Deep learning mengubah paradigma ini: jaringan mempelajari representasi fiturnya sendiri dari data mentah. Inilah yang membuatnya powerful untuk gambar, teks, dan audio.

1. Mengapa Deep Learning?

ML klasik seperti yang dipelajari di P-03 bekerja sangat baik untuk data tabular terstruktur. Tapi ada kelas masalah di mana ia bergumul — dan di situlah deep learning unggul.

Keterbatasan ML Klasik

ML Klasik (Scikit-learn)
  • Membutuhkan feature engineering manual — kamu harus tahu fitur apa yang relevan
  • Performa melandai dengan lebih banyak data (plateau)
  • Kesulitan dengan data tidak terstruktur: gambar, teks, audio
  • Tidak bisa menangkap hierarki fitur secara otomatis
Deep Learning
  • Belajar representasi secara otomatis dari data mentah — tidak perlu feature engineering manual
  • Performa terus meningkat seiring lebih banyak data
  • Sangat kuat untuk gambar, teks, audio, dan data sekuensial
  • Mampu menangkap hierarki fitur berlapis (tepi → bentuk → objek)

Faktor Pemungkin Deep Learning Modern

Deep learning bukan konsep baru — idenya sudah ada sejak 1980-an. Yang berubah adalah tiga faktor yang membuatnya praktis:

📊
Data Berlimpah
ImageNet (14 juta gambar), Common Crawl (web seluruh dunia), dataset terlabeli dalam jumlah masif yang tidak ada sebelumnya
🖥️
GPU & TPU
GPU modern 100–1000× lebih cepat untuk matrix multiplication. Google TPU mempercepat training menjadi jam, bukan bulan
🛠️
Framework Modern
TensorFlow, PyTorch, Keras — mengotomatisasi backpropagation, memungkinkan eksperimen dalam hitungan menit, bukan minggu

Fungsi Aktivasi

Fungsi aktivasi memperkenalkan non-linearitas — tanpanya, jaringan berlapis sama saja dengan satu layer linier. Pemilihan aktivasi yang tepat sangat penting untuk performa model.

Sigmoid
σ(z) = 1/(1+e⁻ᶻ)
Output 0–1. Hanya untuk output layer klasifikasi biner. Jangan pakai di hidden layer (vanishing gradient).
ReLU
max(0, z)
Default terbaik untuk hidden layer. Cepat, efektif, atasi vanishing gradient. Gunakan kecuali ada alasan khusus.
Softmax
eᶻⁱ / Σeᶻʲ
Hanya untuk output layer klasifikasi multi-kelas. Menghasilkan distribusi probabilitas yang jumlahnya 1.
Tanh
(eᶻ − e⁻ᶻ)/(eᶻ + e⁻ᶻ)
Output −1 sampai 1. Lebih baik dari sigmoid di hidden layer. Dipakai di RNN/LSTM untuk gating mechanism.

3. Mekanisme Training

Cara neural network "belajar" adalah dengan terus-menerus mengukur seberapa salah prediksinya, lalu menyesuaikan semua weight untuk mengurangi kesalahan itu. Proses ini berulang ribuan kali.

➡️
Forward Pass
Data masuk, mengalir maju layer per layer, menghasilkan prediksi ŷ
x → ŷ
📏
Hitung Loss
Ukur seberapa salah prediksi dibandingkan label y yang sebenarnya
L(y, ŷ)
⬅️
Backprop
Hitung gradient loss terhadap setiap weight menggunakan chain rule
∂L/∂w
🔄
Update Weight
Kurangi weight dengan gradient × learning rate agar loss mengecil
w ← w − η·∂L/∂w
🔁
Ulangi
Lakukan untuk semua batch data, berulang selama N epoch hingga konvergen
t = 1, 2, ..., N

Fungsi Loss

Problem Loss Function Formula Keras
Regresi MSE (Mean Squared Error) Σ(y − ŷ)² / n 'mse'
Klasifikasi biner Binary Cross-Entropy −(y·log ŷ + (1−y)·log(1−ŷ)) 'binary_crossentropy'
Klasifikasi multi-kelas Categorical Cross-Entropy −Σ yᵢ·log ŷᵢ 'sparse_categorical_crossentropy'

Learning Rate & Optimizer

Learning rate (η) adalah hyperparameter paling penting dalam deep learning. Terlalu besar → loss oscillates. Terlalu kecil → training sangat lambat dan terjebak di local minimum.

Validation loss Training loss Learning rate: 0.001 · Optimizer: Adam

Setelah epoch ke-~30, validation loss mulai naik sementara training loss terus turun — tanda overfitting. Gunakan Early Stopping untuk menghentikan training di titik optimal.

Adam
Default terbaik. Adaptive learning rate per parameter. Konvergen cepat, robust, jarang butuh tuning learning rate manual.
SGD + Momentum
Stochastic Gradient Descent dengan momentum. Lebih lambat konvergen tapi sering menghasilkan model yang lebih general. Populer untuk training ulang dari scratch.
RMSprop
Direkomendasikan untuk RNN. Mengatasi masalah learning rate yang mengecil terus-menerus (ada di plain SGD).

Regularisasi: Mencegah Overfitting

Dropout
Secara acak menonaktifkan p% neuron selama training. Memaksa jaringan belajar representasi yang redundant dan lebih robust.
Keras: Dropout(0.3)
Early Stopping
Hentikan training ketika validation loss tidak membaik selama N epoch berturut-turut. Simpan model terbaik, bukan model akhir.
Keras: EarlyStopping(patience=5)
Batch Normalization
Normalisasi output tiap layer selama training. Mempercepat konvergensi, memungkinkan learning rate lebih besar, dan memiliki efek regularisasi ringan.
Keras: BatchNormalization()

5. Ekosistem TensorFlow / Keras

Keras adalah high-level API yang berjalan di atas TensorFlow, dirancang agar membangun neural network semudah menyusun blok LEGO. Sejak TF 2.0, Keras adalah interface default TensorFlow.

Sequential API

Untuk model linier — satu input, satu output, layer berurutan. 90% kebutuhan DL dicakup dengan ini.

sequential_model.py Keras
import tensorflow as tf from tensorflow import keras model = keras.Sequential([ keras.layers.Dense(128, activation='relu', input_shape=(20,)), keras.layers.Dropout(0.3), keras.layers.Dense(64, activation='relu'), keras.layers.Dense(1, activation='sigmoid') ]) model.compile( optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'] ) model.summary() # cetak arsitektur

Training & Evaluasi

Setelah compile, training hanya membutuhkan satu baris — Keras mengurus semua detail backprop secara otomatis.

train_evaluate.py Keras
from tensorflow.keras.callbacks import ( EarlyStopping, ModelCheckpoint ) callbacks = [ EarlyStopping(monitor='val_loss', patience=5, restore_best_weights=True), ModelCheckpoint('best_model.h5', save_best_only=True) ] history = model.fit( X_train, y_train, epochs=50, batch_size=32, validation_split=0.2, callbacks=callbacks, verbose=1 ) # Evaluasi pada test set loss, acc = model.evaluate(X_test, y_test) print(f"Test accuracy: {acc:.4f}")

6. Kapan Pakai Deep Learning?

Deep learning bukan perak ajaib untuk semua masalah. Ada kondisi spesifik di mana DL jauh lebih unggul — dan kondisi lain di mana ML klasik lebih tepat, lebih cepat, dan lebih mudah dijelaskan.

Kondisi Pilihan Alasan
Data < 1.000 sampel ✗ DL  ✓ ML Klasik DL butuh banyak data untuk generalisasi. Dengan data sedikit, Random Forest atau SVM hampir pasti menang.
Data tabular terstruktur ○ DL  ✓ ML Klasik Gradient Boosting (XGBoost, LightGBM) secara konsisten mengalahkan DL di data tabular. DL tidak memiliki inductive bias yang tepat untuk struktur ini.
Data gambar / video ✓ DL (CNN) CNN adalah state-of-the-art yang tidak tertandingi untuk data spasial. ML klasik memerlukan feature engineering manual yang sangat sulit untuk gambar.
Data teks / NLP ✓ DL (Transformer) BERT, GPT, dan Transformer architecture telah merevolusi NLP. Untuk teks panjang dan nuansa bahasa, DL tidak ada tandingannya.
Time series / Sensor IoT ✓ DL (LSTM) atau ○ ML Tergantung kompleksitas pola. ARIMA masih kompetitif untuk time series sederhana. LSTM unggul untuk pola jangka panjang kompleks dan multivariate.
Butuh interpretabilitas tinggi ✗ DL  ✓ ML Klasik DL adalah black box. Di konteks medis, hukum, atau kredit perbankan — regulatory requirement sering mengharuskan model yang bisa dijelaskan (explainable AI).
Resource komputasi terbatas ✗ DL  ✓ ML Klasik DL butuh GPU dan training berjam-jam. Jika model harus berjalan di edge device atau server murah, ML klasik yang teroptimasi lebih praktis.
Data tidak berlabel berlimpah ✓ DL (Self-supervised) Transfer learning dan self-supervised learning memungkinkan DL memanfaatkan data tidak berlabel dalam jumlah besar — sesuatu yang ML klasik tidak bisa lakukan.
⚠️

Anti-pattern paling umum: Langsung pakai DL untuk data tabular kecil karena terdengar lebih keren atau "modern". Selalu mulai dengan baseline sederhana (Logistic Regression, Random Forest), ukur performanya, dan beralih ke DL hanya jika ada gap performa yang signifikan dan kamu punya cukup data serta resource.

Ringkasan Pertemuan Ini

  • Deep learning unggul karena bisa belajar representasi fitur secara otomatis dari data mentah — tidak perlu feature engineering manual seperti ML klasik
  • Neuron buatan: weighted sum + bias → activation function → output. Dirangkai berlapis membentuk jaringan yang bisa belajar fungsi arbitrarily complex
  • Training: forward pass (prediksi) → hitung loss → backpropagation (gradient) → update weight → ulangi sampai konvergen
  • ReLU untuk hidden layer, Sigmoid untuk output biner, Softmax untuk output multi-kelas — ini adalah default yang hampir selalu benar
  • Tiga arsitektur utama: ANN/MLP (tabular), CNN (gambar/spasial), RNN/LSTM (sekuensial/teks/time series)
  • Keras Sequential API: define layer → compile dengan optimizer+loss → fit dengan callback (EarlyStopping) → evaluate
  • DL bukan selalu lebih baik — untuk data tabular kecil, Gradient Boosting hampir selalu menang. Pilih alat berdasarkan karakteristik masalah, bukan popularitas
