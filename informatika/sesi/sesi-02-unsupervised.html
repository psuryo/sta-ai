Unsupervised Learning

Penjelasan mendalam tiga algoritma unsupervised learning — K-Means Clustering, DBSCAN, dan PCA. Memahami cara kerjanya, kapan menggunakannya, dan bagaimana mengimplementasikannya dengan Scikit-learn.

3 Algoritma Clustering & Reduksi Dimensi Scikit-learn

Apa itu Unsupervised Learning?

Unsupervised learning adalah paradigma machine learning di mana model bekerja dengan data tanpa label. Tidak ada "jawaban benar" yang diberikan — model harus sendiri menemukan struktur, pola, atau representasi tersembunyi dalam data.

📌

Halaman ini adalah referensi mendalam. Untuk gambaran umum, kembali ke P-02 — Bagian 3: Algoritma Fundamental. Halaman ini cocok dibaca saat kamu ingin memahami cara kerja, hyperparameter, dan kapan menggunakan masing-masing algoritma secara lebih detail.

Clustering
Mengelompokkan data serupa
Menemukan kelompok alami dalam data berdasarkan kemiripan. Tidak ada label kelas — model sendiri yang memutuskan mana yang "mirip".
Algoritma: K-Means, DBSCAN, Hierarchical
Reduksi Dimensi
Menyederhanakan representasi data
Mengurangi jumlah fitur sambil mempertahankan informasi paling penting. Berguna untuk visualisasi, kompresi, dan preprocessing.
Algoritma: PCA, t-SNE, UMAP, Autoencoder

1. K-Means Clustering

01 / 03
K-Means Clustering
sklearn.cluster.KMeans
Algoritma clustering paling populer dan paling mudah dipahami. Membagi data ke dalam k kelompok (cluster) sehingga setiap titik data masuk ke cluster yang centroid-nya paling dekat. Bekerja secara iteratif sampai posisi centroid tidak berubah.
Clustering Cepat & Skalabel Perlu Tentukan k

Cara Kerja: Algoritma Lloyd

K-Means bekerja melalui empat langkah yang diulang sampai konvergen:

01
Inisialisasi — Pilih k titik sebagai centroid awal (secara acak, atau dengan metode K-Means++ yang lebih cerdas)
02
Assignment — Setiap titik data ditetapkan ke cluster dengan centroid terdekat (menggunakan Euclidean distance)
03
Update — Hitung ulang posisi centroid sebagai rata-rata semua titik dalam cluster tersebut
04
Ulangi — Kembali ke langkah 02 sampai tidak ada titik yang berpindah cluster (konvergen), atau batas iterasi tercapai
Visualisasi — K-Means dengan k=3
● centroid
Tiga cluster dengan warna berbeda. Centroid (titik besar) adalah rata-rata posisi semua anggota clusternya.

Masalah Utama: Menentukan Nilai k

K-Means membutuhkan kamu menentukan jumlah cluster sebelum training. Dua metode paling umum:

Elbow Method
Plot nilai WCSS (Within-Cluster Sum of Squares) untuk berbagai nilai k. Cari "siku" di mana penurunan WCSS mulai melambat — itulah k optimal.
k=1
k=2
k=3
k=4
k=5
k=6
k=3 adalah "siku" — penambahan cluster setelahnya tidak banyak mengurangi WCSS.
Silhouette Score
Mengukur seberapa baik setiap titik cocok di clusternya sendiri dibanding cluster terdekat lainnya. Nilai −1 sampai +1 — semakin mendekati +1, semakin baik.
k=2 → score: 0.52
k=3 → score: 0.71 ✓
k=4 → score: 0.63
k=5 → score: 0.58
Pilih k dengan silhouette score tertinggi.
Kelebihan
  • Sederhana dan mudah dipahami
  • Cepat dan efisien, skala baik ke dataset besar
  • Mudah diimplementasikan
  • Bekerja baik untuk cluster berbentuk bulat (spherical)
Kekurangan
  • Harus menentukan k di awal
  • Sensitif terhadap inisialisasi awal centroid
  • Tidak bekerja baik untuk cluster non-spherical
  • Sensitif terhadap outlier — centroid tertarik ke outlier

Hyperparameter Penting

n_clusters (k)
Jumlah cluster yang diinginkan. Hyperparameter paling kritis. Gunakan Elbow Method atau Silhouette Score untuk menentukannya secara empiris.
init
k-means++ (default) — inisialisasi cerdas yang menyebarkan centroid awal. Jauh lebih baik dari inisialisasi acak. Hampir selalu gunakan k-means++.
n_init
Berapa kali K-Means dijalankan dengan inisialisasi berbeda. Default 10. Naikkan ke 20–50 jika hasil tidak stabil.
max_iter
Jumlah iterasi maksimum per run. Default 300 sudah cukup untuk kebanyakan kasus.

Implementasi Scikit-learn

from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import silhouette_score
import matplotlib.pyplot as plt

# PENTING: scale dulu sebelum clustering
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# ── Elbow Method ──
wcss = []
k_range = range(1, 11)
for k in k_range:
    km = KMeans(n_clusters=k, init='k-means++', n_init=10, random_state=42)
    km.fit(X_scaled)
    wcss.append(km.inertia_)

plt.plot(k_range, wcss, 'bo-')
plt.xlabel('Jumlah Cluster (k)'); plt.ylabel('WCSS')
plt.title('Elbow Method'); plt.show()

# ── Silhouette Score ──
for k in range(2, 8):
    km = KMeans(n_clusters=k, init='k-means++', n_init=10, random_state=42)
    labels = km.fit_predict(X_scaled)
    score = silhouette_score(X_scaled, labels)
    print(f"k={k}: silhouette = {score:.3f}")

# ── Clustering final ──
kmeans = KMeans(n_clusters=3, init='k-means++', n_init=10, random_state=42)
labels = kmeans.fit_predict(X_scaled)

print(f"Distribusi cluster: {pd.Series(labels).value_counts().to_dict()}")
💡

Validasi clustering: Karena tidak ada label, evaluasi clustering lebih sulit. Selain metrik internal (silhouette score), lakukan juga visual inspection — plot cluster dengan 2 fitur terpenting atau setelah reduksi dimensi dengan PCA. Jika cluster masuk akal secara domain, itulah yang terpenting.

2. DBSCAN

02 / 03
DBSCAN
sklearn.cluster.DBSCAN — Density-Based Spatial Clustering of Applications with Noise
Algoritma clustering berbasis kepadatan (density). Tidak perlu menentukan jumlah cluster di awal — cluster terbentuk secara otomatis dari wilayah yang padat, dan titik yang terisolasi diklasifikasikan sebagai noise (anomali). Unggul saat cluster berbentuk tidak beraturan.
Clustering Deteksi Anomali Density-Based Bebas Tentukan k

Konsep Dasar: Tiga Tipe Titik

DBSCAN mengklasifikasikan setiap titik data berdasarkan dua parameter: eps (radius lingkaran) dan min_samples (jumlah tetangga minimum).

🔵
CORE POINT
Memiliki ≥ min_samples tetangga dalam radius eps. Titik inti dari sebuah cluster.
🟡
BORDER POINT
Bukan core point, tapi berada dalam radius eps dari sebuah core point. Anggota cluster di tepi.
⭕
NOISE / OUTLIER
Bukan core point dan tidak dalam radius eps dari core point manapun. Dianggap anomali — diberi label -1.
Visualisasi — DBSCAN: Cluster & Noise
⬜ noise (label −1)
DBSCAN menemukan 3 cluster dengan bentuk tidak beraturan. Titik abu-abu (noise) tidak masuk cluster manapun — inilah kekuatan DBSCAN untuk deteksi anomali.

Cara Kerja

Untuk setiap titik yang belum dikunjungi:

  1. Temukan semua tetangga dalam radius eps
  2. Jika jumlah tetangga ≥ min_samples → titik ini adalah core point, buat cluster baru
  3. Ekspansi cluster secara rekursif: tambahkan semua titik dalam jangkauan (dan titik yang mereka jangkau pula)
  4. Jika jumlah tetangga < min_samples dan tidak terjangkau core point → tandai sebagai noise (label −1)
Kelebihan
  • Tidak perlu menentukan k di awal
  • Menemukan cluster berbentuk arbitrary
  • Secara otomatis mengidentifikasi outlier/noise
  • Tahan terhadap outlier — tidak mengacaukan cluster
Kekurangan
  • Sensitif terhadap pilihan eps dan min_samples
  • Tidak bekerja baik pada data dengan kepadatan bervariasi
  • Lambat pada dataset sangat besar (O(n²) worst case)
  • Tidak bisa langsung predict data baru

Hyperparameter Penting

eps
Radius lingkaran tetangga. Hyperparameter paling kritis. Terlalu kecil → semua titik jadi noise. Terlalu besar → semua titik masuk satu cluster. Cara menentukan: plot k-distance graph — cari "siku".
min_samples
Jumlah titik minimum untuk membentuk core point. Aturan umum: min_samples = 2 × n_features sebagai titik awal. Nilai lebih besar → cluster lebih ketat, lebih banyak noise.
metric
Fungsi jarak. Default euclidean. Gunakan manhattan untuk data berdimensi tinggi, atau cosine untuk data teks.

Implementasi Scikit-learn

from sklearn.cluster import DBSCAN
from sklearn.neighbors import NearestNeighbors
from sklearn.preprocessing import StandardScaler
import numpy as np
import matplotlib.pyplot as plt

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# ── Langkah 1: K-Distance Graph untuk menentukan eps ──
k = 2 * X.shape[1]   # min_samples = 2 × n_features sebagai titik awal
nbrs = NearestNeighbors(n_neighbors=k).fit(X_scaled)
distances, _ = nbrs.kneighbors(X_scaled)
distances = np.sort(distances[:, k-1])

plt.plot(distances)
plt.xlabel('Titik data (diurutkan)'); plt.ylabel('Jarak ke tetangga ke-k')
plt.title('K-Distance Graph — cari "siku" untuk eps')
plt.axhline(y=0.5, color='r', linestyle='--', label='eps kandidat')
plt.legend(); plt.show()

# ── Langkah 2: Jalankan DBSCAN ──
dbscan = DBSCAN(eps=0.5, min_samples=k)
labels = dbscan.fit_predict(X_scaled)

n_clusters = len(set(labels)) - (1 if -1 in labels else 0)
n_noise    = list(labels).count(-1)
print(f"Cluster ditemukan: {n_clusters}")
print(f"Noise points     : {n_noise} ({n_noise/len(labels)*100:.1f}%)")

# Label -1 = anomali — berguna untuk deteksi fraud
anomalies = X[labels == -1]
print(f"Anomali terdeteksi: {len(anomalies)} titik")
🔍

DBSCAN untuk deteksi anomali: Label -1 adalah "anomali" yang secara eksplisit teridentifikasi. Ini menjadikan DBSCAN alat yang sangat berguna untuk fraud detection, network intrusion detection, dan quality control manufaktur — kasus di mana kamu ingin menemukan titik-titik "aneh" yang tidak cocok dengan pola normal.

3. PCA — Principal Component Analysis

03 / 03
Principal Component Analysis (PCA)
sklearn.decomposition.PCA
Teknik reduksi dimensi paling fundamental. PCA menemukan arah-arah di mana data paling "tersebar" (variansi terbesar) dan memproyeksikan data ke arah-arah tersebut. Hasilnya adalah representasi data yang lebih ringkas namun mempertahankan informasi paling penting.
Reduksi Dimensi Visualisasi Preprocessing

Mengapa Reduksi Dimensi Diperlukan?

Dataset nyata sering memiliki puluhan hingga ribuan fitur. Dimensi tinggi menghadirkan beberapa masalah:

CURSE OF DIMENSIONALITY
Di dimensi tinggi, semua titik data menjadi "jauh" satu sama lain — jarak kehilangan makna, membuat banyak algoritma gagal.
OVERFITTING
Fitur berlebihan yang berkorelasi tinggi atau tidak relevan meningkatkan risiko model menghafal noise.
VISUALISASI
Tidak bisa memvisualisasikan data berdimensi lebih dari 3. PCA memungkinkan visualisasi ke 2D atau 3D.

Cara Kerja: Mencari Arah Variansi Terbesar

PCA menemukan principal components — sumbu-sumbu baru yang merupakan kombinasi linier dari fitur asli:

  • PC1 adalah arah dengan variansi data terbesar
  • PC2 adalah arah dengan variansi terbesar yang tegak lurus terhadap PC1
  • PC3, dst. mengikuti pola yang sama

Secara matematis, PCA melakukan eigendecomposition terhadap matriks kovariansi data. Intuisinya: PCA merotasi sistem koordinat agar variansi terbesar berada di sumbu pertama.

Visualisasi — PCA: Arah Principal Components
PC1 →
PC2
PC1 (teal) menangkap variansi terbesar. PC2 (amber) tegak lurus terhadap PC1, menangkap variansi terbesar yang tersisa.

Explained Variance: Berapa Dimensi yang Perlu Dipertahankan?

Setiap principal component menjelaskan sebagian variansi data. Pilih jumlah komponen yang cukup untuk menjelaskan ≥ 95% total variansi — ini mempertahankan sebagian besar informasi sambil mengurangi dimensi secara signifikan.

Kelebihan
  • Mengurangi dimensi data secara efektif
  • Menghilangkan korelasi antar fitur (orthogonal components)
  • Mempercepat training model downstream
  • Memungkinkan visualisasi data berdimensi tinggi
  • Bisa mengurangi noise dalam data
Kekurangan
  • Principal components tidak interpretable
  • Kehilangan sebagian informasi
  • Hanya menangkap hubungan linier
  • Wajib feature scaling sebelum PCA

Hyperparameter Penting

n_components
Jumlah principal component yang dipertahankan. Bisa integer (jumlah komponen) atau float 0–1 (contoh: 0.95 = pertahankan hingga 95% variansi terjelas). Gunakan float untuk kemudahan.
svd_solver
auto (default) memilih solver terbaik otomatis. randomized jauh lebih cepat untuk dataset besar berdimensi tinggi dengan sedikit komponen yang dibutuhkan.
whiten
Jika True, hasil PCA dinormalisasi sehingga setiap komponen memiliki variansi 1. Berguna sebagai preprocessing sebelum SVM atau k-NN.

Implementasi Scikit-learn

from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
import matplotlib.pyplot as plt
import numpy as np

# PENTING: selalu scale sebelum PCA
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# ── Analisis berapa komponen yang diperlukan ──
pca_full = PCA().fit(X_scaled)
cumvar = np.cumsum(pca_full.explained_variance_ratio_)

plt.plot(range(1, len(cumvar)+1), cumvar, 'bo-')
plt.axhline(y=0.95, color='r', linestyle='--', label='95% threshold')
plt.xlabel('Jumlah Komponen'); plt.ylabel('Cumulative Explained Variance')
plt.legend(); plt.show()

# ── Terapkan PCA dengan n_components optimal ──
pca = PCA(n_components=0.95)   # pertahankan 95% variansi
X_pca = pca.fit_transform(X_scaled)

print(f"Dimensi asli       : {X_scaled.shape[1]} fitur")
print(f"Dimensi setelah PCA: {X_pca.shape[1]} komponen")
print(f"Variansi dijelaskan: {pca.explained_variance_ratio_.sum():.3f}")

# ── Visualisasi 2D ──
pca_2d = PCA(n_components=2)
X_2d = pca_2d.fit_transform(X_scaled)

plt.figure(figsize=(8, 6))
colors = ['#00C9B1', '#9B7CF4', '#F5A623']
for i, cls in enumerate(class_names):
    mask = y == i
    plt.scatter(X_2d[mask, 0], X_2d[mask, 1], c=colors[i], label=cls, alpha=0.7)
plt.xlabel(f"PC1 ({pca_2d.explained_variance_ratio_[0]:.1%} var)")
plt.ylabel(f"PC2 ({pca_2d.explained_variance_ratio_[1]:.1%} var)")
plt.legend(); plt.show()

# ── PCA sebagai preprocessing dalam Pipeline ──
from sklearn.pipeline import Pipeline
from sklearn.svm import SVC

pipeline = Pipeline([
    ('scaler', StandardScaler()),
    ('pca',    PCA(n_components=0.95)),
    ('clf',    SVC(kernel='rbf'))
])
pipeline.fit(X_train, y_train)
print(f"Test accuracy dengan PCA+SVM: {pipeline.score(X_test, y_test):.3f}")
⚠️

Data leakage pada PCA: PCA harus di-fit hanya pada data training, lalu di-transform ke data test. Gunakan selalu Pipeline dari Scikit-learn untuk memastikan ini — jangan pernah fit_transform pada seluruh dataset sebelum split.

Perbandingan & Panduan Memilih

Algoritma Tujuan Perlu Tentukan k/dim Deteksi Anomali Skala ke Data Besar Terbaik Untuk
K-Means Clustering Ya — harus tentukan k Tidak Sangat baik Segmentasi pelanggan, cluster berbentuk bulat, dataset besar
DBSCAN Clustering Tidak — otomatis Ya — bawaan Sedang Cluster tidak beraturan, deteksi fraud/anomali, data geografis
PCA Reduksi Dimensi Ya — tentukan n_components Tidak langsung Baik Visualisasi, preprocessing sebelum ML, kompresi fitur

Alur Keputusan

🗺️
  1. Apakah tujuanmu mengelompokkan data? → pilih Clustering
  2. Apakah tujuanmu menyederhanakan/visualisasi data? → pilih PCA
  3. Untuk clustering: apakah cluster kemungkinan berbentuk bulat dan jumlahnya diketahui? → K-Means
  4. Untuk clustering: apakah cluster bentuknya tidak beraturan atau kamu perlu deteksi anomali? → DBSCAN
  5. Sebelum supervised learning dengan data berdimensi tinggi → gunakan PCA sebagai preprocessing
  6. Untuk visualisasi data berdimensi tinggi → PCA (cepat, linier) atau t-SNE/UMAP (lebih baik untuk struktur non-linier)

Tantangan Umum Unsupervised Learning

Evaluasi Sulit
Tidak ada "jawaban benar" — evaluasi bergantung pada metrik internal (silhouette score, WCSS) dan domain expertise. Selalu validasi hasil dengan visualisasi dan knowledge bisnis.
Wajib Preprocessing
Semua algoritma unsupervised sangat sensitif terhadap skala fitur. Selalu lakukan StandardScaler sebelum K-Means, DBSCAN, maupun PCA.
📋 Latihan: Segmentasi Pelanggan

Cari dataset pelanggan di Kaggle (contoh: "Mall Customers", "Customer Segmentation"). Lakukan:

  1. EDA dan preprocessing — scaling, handle missing values
  2. Gunakan PCA untuk visualisasi — plot 2D dan amati apakah ada cluster yang terlihat
  3. Jalankan K-Means — tentukan k optimal dengan Elbow Method dan Silhouette Score
  4. Jalankan DBSCAN — bandingkan cluster yang ditemukan dengan K-Means, amati titik noise
  5. Interpretasikan tiap cluster: apa karakteristik pelanggan di masing-masing kelompok?
