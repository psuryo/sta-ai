6 Algoritma Klasifikasi & Regresi Scikit-learn

Apa itu Supervised Learning?

Supervised learning adalah paradigma machine learning di mana model dilatih menggunakan data berlabel — setiap sampel input x memiliki pasangan output y yang diketahui. Tujuannya adalah mempelajari fungsi f(x) → y sehingga model dapat memprediksi output untuk input baru yang belum pernah dilihat.

1. Linear & Logistic Regression

01 / 06
Linear & Logistic Regression
sklearn.linear_model.LinearRegression · LogisticRegression
Keluarga model paling sederhana dan paling sering digunakan sebagai baseline. Linear Regression memodelkan hubungan linier antara fitur dan target numerik; Logistic Regression menggunakannya untuk klasifikasi dengan fungsi sigmoid.
Klasifikasi Regresi Interpretable Baseline

Cara Kerja

Linear Regression mencari garis (atau hyperplane di dimensi tinggi) yang meminimalkan jumlah kuadrat selisih antara nilai prediksi dan nilai aktual (disebut Ordinary Least Squares).

Fungsi prediksi: ŷ = β₀ + β₁x₁ + β₂x₂ + ... + βₙxₙ

Model belajar menemukan nilai koefisien (β) yang optimal sehingga error prediksi sekecil mungkin.

Logistic Regression menggunakan output linear yang sama, tetapi membungkusnya dengan fungsi sigmoid untuk menghasilkan probabilitas (0–1):

P(y=1|x) = 1 / (1 + e⁻ᶻ)  di mana z = β₀ + β₁x₁ + ...

Jika probabilitas ≥ 0.5 → prediksi kelas 1; jika < 0.5 → kelas 0. Batas keputusan (decision boundary) adalah garis yang memisahkan kedua kelas.

Visualisasi Intuitif — Regresi Linier
Garis regresi meminimalkan total jarak kuadrat semua titik data ke garis tersebut.
Kelebihan
  • Sangat cepat dilatih dan diprediksi
  • Koefisien mudah diinterpretasikan
  • Baseline yang kuat — wajib dicoba pertama
  • Tidak rentan overfit pada data besar
  • Bekerja baik saat hubungan benar-benar linier
Kekurangan
  • Tidak bisa menangkap pola non-linier
  • Sensitif terhadap outlier
  • Asumsi independensi fitur sering dilanggar
  • Perlu feature scaling untuk konvergensi optimal
  • Performa rendah jika fitur berkorelasi tinggi (multikolinearitas)

Hyperparameter Penting

C (LogReg)
Invers kekuatan regularisasi. C kecil → regularisasi kuat (model lebih sederhana, kurangi overfit). C besar → regularisasi lemah (model lebih fleksibel). Default: 1.0.
penalty
l2 (Ridge, default) mengurangi semua koefisien secara proporsional. l1 (Lasso) mendorong koefisien menjadi nol — berguna untuk feature selection otomatis.
solver
Algoritma optimasi. lbfgs untuk dataset kecil-menengah; saga untuk dataset besar dan mendukung l1. Jarang perlu diganti dari default.
max_iter
Jumlah iterasi maksimum untuk konvergensi. Naikkan (misal 500 atau 1000) jika muncul peringatan ConvergenceWarning.

Implementasi Scikit-learn

from sklearn.linear_model import LogisticRegression, LinearRegression
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline
from sklearn.metrics import classification_report

# Klasifikasi — Logistic Regression
clf_pipeline = Pipeline([
    ('scaler', StandardScaler()),          # wajib: LR sensitif terhadap skala fitur
    ('clf', LogisticRegression(
        C=1.0,                               # regularisasi — coba 0.01, 0.1, 1, 10
        penalty='l2',                        # 'l1' untuk feature selection
        max_iter=500,
        random_state=42
    ))
])
clf_pipeline.fit(X_train, y_train)
y_pred = clf_pipeline.predict(X_test)
print(classification_report(y_test, y_pred))

# Lihat koefisien — ini kekuatan utama LR
model = clf_pipeline.named_steps['clf']
import pandas as pd
coef_df = pd.DataFrame({
    'fitur': feature_names,
    'koefisien': model.coef_[0]
}).sort_values('koefisien', ascending=False)
print(coef_df)
💡

Kapan menggunakan Logistic Regression: Selalu mulai dari sini sebagai baseline. Jika akurasi sudah cukup, tidak perlu lanjut ke model yang lebih kompleks. Juga pilihan terbaik saat kamu perlu menjelaskan mengapa model mengambil keputusan tertentu kepada stakeholder non-teknis.

2. Decision Tree

02 / 06
Decision Tree
sklearn.tree.DecisionTreeClassifier · DecisionTreeRegressor
Model berbentuk pohon keputusan yang membagi data secara rekursif berdasarkan fitur paling informatif. Hasilnya adalah serangkaian aturan if-else yang mudah dipahami manusia.
Klasifikasi Regresi Interpretable Non-linear

Cara Kerja

Algoritma membangun pohon secara top-down, mulai dari seluruh dataset di root node. Di setiap node, ia memilih fitur dan threshold yang paling baik memisahkan kelas, menggunakan kriteria seperti Gini Impurity atau Information Gain.

  • Gini Impurity: mengukur seberapa "kotor" sebuah node — 0 berarti node murni (satu kelas). Semakin rendah, semakin baik.
  • Information Gain (Entropy): mengukur penurunan ketidakpastian setelah split. Model memilih split yang memaksimalkan information gain.

Proses ini diulang secara rekursif hingga semua daun (leaf nodes) murni, atau kondisi berhenti terpenuhi (misal: kedalaman maksimum, jumlah sampel minimum).

Kelebihan
  • Mudah divisualisasi dan dijelaskan
  • Tidak butuh feature scaling
  • Menangani fitur numerik dan kategorik
  • Implisit melakukan feature selection
  • Cepat untuk dataset kecil-menengah
Kekurangan
  • Mudah overfit — pohon dalam tanpa pruning menghafal data
  • Tidak stabil — data sedikit berubah → pohon berubah besar
  • Bias terhadap fitur dengan banyak nilai unik
  • Performa lebih rendah dari ensemble (RF/XGBoost)

Hyperparameter Penting

max_depth
Kedalaman maksimum pohon. Paling penting untuk mencegah overfit. Mulai dari 3–5 dan naikkan bertahap. Default: None (tidak dibatasi = overfit parah).
min_samples_split
Jumlah sampel minimum di sebuah node agar bisa di-split. Nilai lebih besar = pohon lebih konservatif. Default: 2.
min_samples_leaf
Jumlah sampel minimum di leaf node. Cegah daun yang berisi hanya 1-2 sampel (overfit). Default: 1.
criterion
gini (default, lebih cepat) atau entropy (information gain). Dalam praktik perbedaannya kecil — cukup gunakan gini.

Implementasi Scikit-learn

from sklearn.tree import DecisionTreeClassifier, export_text, plot_tree
import matplotlib.pyplot as plt

dt = DecisionTreeClassifier(
    max_depth=4,              # batasi kedalaman untuk cegah overfit
    min_samples_leaf=5,       # setiap daun minimal 5 sampel
    criterion='gini',
    random_state=42
)
dt.fit(X_train, y_train)
print(f"Train acc: {dt.score(X_train, y_train):.3f}")
print(f"Test  acc: {dt.score(X_test, y_test):.3f}")

# Visualisasi pohon dalam bentuk teks
print(export_text(dt, feature_names=feature_names))

# Visualisasi pohon dalam bentuk grafis
plt.figure(figsize=(16, 8))
plot_tree(dt, feature_names=feature_names, class_names=class_names,
          filled=True, rounded=True)
plt.show()
⚠️

Perhatikan overfit: Jika train accuracy jauh lebih tinggi dari test accuracy (misal 99% vs 75%), pohon terlalu dalam. Kurangi max_depth atau naikkan min_samples_leaf. Decision Tree tanpa pembatasan hampir selalu overfit.

3. Random Forest

03 / 06
Random Forest
sklearn.ensemble.RandomForestClassifier · RandomForestRegressor
Ensemble dari banyak Decision Tree yang dilatih pada subsampel data dan fitur yang berbeda-beda (teknik ini disebut bagging). Prediksi akhir ditentukan oleh voting mayoritas (klasifikasi) atau rata-rata (regresi). Lebih kuat dan tahan overfit dibanding satu Decision Tree.
Klasifikasi Regresi Ensemble Tahan Overfit

Cara Kerja: Bagging + Random Feature Subspace

Random Forest menggabungkan dua ide utama:

  1. Bootstrap Aggregating (Bagging): Setiap pohon dilatih pada sampel acak dengan penggantian dari dataset asli. Sekitar 37% data tidak terambil per pohon — ini disebut out-of-bag (OOB) samples dan bisa digunakan sebagai validasi internal.
  2. Random Feature Subspace: Di setiap split, hanya sebagian kecil fitur yang dipertimbangkan (biasanya √n_fitur untuk klasifikasi). Ini memastikan pohon-pohon yang dihasilkan beragam dan tidak berkorelasi satu sama lain.

Karena setiap pohon membuat keputusan berdasarkan data dan fitur yang berbeda, error satu pohon tidak berkorelasi dengan error pohon lain. Saat di-voting/rata-rata, error-error ini saling menghapus — ini yang membuat ensemble jauh lebih akurat.

Kelebihan
  • Akurasi tinggi, tahan overfit secara alami
  • Memberikan feature importance yang reliabel
  • Tidak perlu feature scaling
  • Toleran terhadap missing values dan outlier
  • OOB score = validasi gratis tanpa validation set
Kekurangan
  • Model besar — lambat diprediksi di produksi
  • Sulit diinterpretasikan (black box)
  • Kurang optimal untuk data sangat sparse (NLP)
  • Membutuhkan lebih banyak memori dari single tree

Hyperparameter Penting

n_estimators
Jumlah pohon dalam forest. Lebih banyak = lebih baik, tapi ada titik diminishing return. 100–500 biasanya sudah cukup. Monitor OOB score untuk menentukan titik optimal.
max_features
Jumlah fitur yang dipertimbangkan di setiap split. sqrt (default klasifikasi) = √n_features. log2 untuk dataset berdimensi tinggi. Nilai lebih kecil → pohon lebih beragam → ensemble lebih kuat.
max_depth
Kedalaman maksimum setiap pohon. Berbeda dengan Decision Tree, RF sudah tahan overfit secara alami — sering dibiarkan None. Batasi jika memori atau kecepatan jadi masalah.
oob_score
Set ke True untuk mendapatkan estimasi performa gratis menggunakan out-of-bag samples. Berguna sebagai pengganti cross-validation cepat.

Implementasi Scikit-learn

from sklearn.ensemble import RandomForestClassifier
import matplotlib.pyplot as plt
import numpy as np

rf = RandomForestClassifier(
    n_estimators=200,          # 200 pohon — cukup untuk kebanyakan kasus
    max_features='sqrt',       # default untuk klasifikasi
    oob_score=True,            # aktifkan estimasi OOB
    n_jobs=-1,                 # pakai semua CPU core
    random_state=42
)
rf.fit(X_train, y_train)

print(f"OOB Score:  {rf.oob_score_:.3f}")    # estimasi tanpa test set
print(f"Test Score: {rf.score(X_test, y_test):.3f}")

# Feature importance — mana fitur paling berpengaruh?
importances = rf.feature_importances_
sorted_idx = np.argsort(importances)
plt.barh(np.array(feature_names)[sorted_idx], importances[sorted_idx], color='#00C9B1')
plt.xlabel('Feature Importance')
plt.title('Random Forest — Feature Importance')
plt.show()

4. Gradient Boosting (XGBoost)

04 / 06
Gradient Boosting / XGBoost
sklearn.ensemble.GradientBoostingClassifier · xgboost.XGBClassifier
Ensemble yang membangun pohon secara sekuensial, di mana setiap pohon baru berfokus pada memperbaiki kesalahan pohon sebelumnya. Berbeda dengan Random Forest yang membangun pohon secara paralel dan independen. Sering menjadi juara di kompetisi data science untuk tabular data.
Klasifikasi Regresi Boosting State-of-the-art

Cara Kerja: Boosting Sekuensial

Ide inti gradient boosting adalah membangun model yang lebih kuat dari kumpulan model lemah secara bertahap:

  1. Buat prediksi awal (bisa sesederhana rata-rata semua nilai target)
  2. Hitung residual (selisih antara prediksi dan nilai aktual)
  3. Latih pohon baru untuk memprediksi residual tersebut
  4. Tambahkan pohon baru ke model dengan bobot tertentu (learning rate)
  5. Ulangi langkah 2–4 sampai n_estimators pohon terbentuk

Secara matematis, ini adalah optimasi gradient descent di function space — setiap iterasi mengurangi loss function dengan langkah kecil ke arah gradient negatifnya.

Perbandingan: Bagging vs Boosting
BAGGING (Random Forest)
Pohon dibangun paralel dan independen
Setiap pohon belajar dari data berbeda
Kombinasi: voting / rata-rata
Tujuan: kurangi variance
BOOSTING (Gradient Boosting)
Pohon dibangun sekuensial
Setiap pohon belajar dari error pohon sebelumnya
Kombinasi: penjumlahan berbobot
Tujuan: kurangi bias
Kelebihan
  • Akurasi terbaik untuk tabular data terstruktur
  • Menangani missing values secara otomatis (XGBoost)
  • Feature importance yang informatif
  • Mendukung berbagai loss function (custom)
  • Regularisasi bawaan (L1/L2 di XGBoost)
Kekurangan
  • Banyak hyperparameter → butuh tuning lebih hati-hati
  • Lebih lambat dari Random Forest saat training
  • Rentan overfit jika learning rate terlalu besar
  • Tidak baik untuk data non-tabular (citra, teks mentah)

Hyperparameter Penting

n_estimators
Jumlah pohon/iterasi boosting. Berbeda dari RF, terlalu banyak bisa overfit. Gunakan early stopping untuk menemukan nilai optimal secara otomatis.
learning_rate
Hyperparameter paling kritis. Mengontrol kontribusi setiap pohon. Nilai kecil (0.01–0.1) + banyak pohon = lebih akurat tapi lebih lambat. Biasanya learning_rate kecil lebih baik.
max_depth
Kedalaman setiap pohon. Boosting menggunakan weak learners — pohon yang lebih dangkal (3–6) seringkali lebih baik. Pohon dalam mudah overfit.
subsample
Fraksi sampel yang digunakan per iterasi (seperti bagging untuk boosting). 0.8 biasanya baik — menambahkan randomness untuk kurangi overfit.

Implementasi Scikit-learn + XGBoost

# Opsi 1: sklearn built-in
from sklearn.ensemble import GradientBoostingClassifier

gb_sklearn = GradientBoostingClassifier(
    n_estimators=200,
    learning_rate=0.05,        # kecil + banyak pohon = lebih akurat
    max_depth=4,
    subsample=0.8,
    random_state=42
)
gb_sklearn.fit(X_train, y_train)

# Opsi 2: XGBoost (install: pip install xgboost)
from xgboost import XGBClassifier

xgb = XGBClassifier(
    n_estimators=500,
    learning_rate=0.05,
    max_depth=4,
    subsample=0.8,
    eval_metric='logloss',
    early_stopping_rounds=20,  # hentikan jika 20 ronde tidak ada perbaikan
    random_state=42
)
xgb.fit(X_train, y_train,
      eval_set=[(X_test, y_test)],    # pantau performa di validation set
      verbose=50)                     # cetak log setiap 50 ronde
print(f"Best iteration: {xgb.best_iteration}")
🏆

Kapan menggunakan Gradient Boosting: Saat kamu butuh performa terbaik pada tabular data terstruktur dan punya waktu untuk tuning hyperparameter. XGBoost, LightGBM, atau CatBoost adalah pilihan pertama di kompetisi data science. Untuk prototyping cepat, mulai dulu dengan Random Forest.

5. k-Nearest Neighbors (k-NN)

05 / 06
k-Nearest Neighbors
sklearn.neighbors.KNeighborsClassifier · KNeighborsRegressor
Algoritma non-parametrik paling intuitif: prediksi dilakukan berdasarkan k titik data latih yang paling mirip dengan input baru. Tidak ada "fase training" — semua komputasi terjadi saat prediksi (lazy learning).
Klasifikasi Regresi Non-parametric Lazy Learning

Cara Kerja

Untuk memprediksi input baru x:

  1. Hitung jarak antara x dengan semua titik di data training (biasanya menggunakan Euclidean distance)
  2. Ambil k titik terdekat
  3. Untuk klasifikasi: prediksi = kelas yang paling banyak muncul di antara k tetangga
  4. Untuk regresi: prediksi = rata-rata nilai target k tetangga
Visualisasi — k-NN dengan k=3
Titik kuning (query) mencari 3 tetangga terdekat: 2 biru + 1 merah → prediksi: Kelas Biru (voting mayoritas)

Pemilihan Nilai k

Nilai k sangat mempengaruhi perilaku model:

k = 1
Overfit — sangat sensitif terhadap noise. Decision boundary sangat irregular.
k optimal
Sweet spot. Cari dengan cross-validation. Biasanya k = √n_samples sebagai titik awal.
k terlalu besar
Underfit — decision boundary terlalu halus, melewatkan pola penting.
Kelebihan
  • Sangat sederhana, tidak ada asumsi tentang distribusi data
  • Tidak perlu fase training (lazy learner)
  • Secara alami multiclass
  • Mudah dipahami dan diimplementasikan
  • Bisa non-linear dengan pilihan k yang tepat
Kekurangan
  • Prediksi sangat lambat pada dataset besar (hitung jarak ke semua sampel)
  • Memori besar — menyimpan seluruh dataset training
  • Wajib feature scaling — fitur skala besar mendominasi jarak
  • Performa menurun drastis di dimensi tinggi (curse of dimensionality)
  • Sensitif terhadap fitur tidak relevan

Hyperparameter Penting

n_neighbors (k)
Jumlah tetangga. Gunakan angka ganjil untuk klasifikasi biner (menghindari seri). Cari nilai terbaik dengan GridSearchCV.
metric
euclidean (default, jarak lurus) atau manhattan (jarak kota/L1, lebih tahan outlier) atau minkowski (generalisasi keduanya). Untuk fitur kategorik, pertimbangkan Hamming distance.
weights
uniform (default) = semua tetangga berbobot sama. distance = tetangga lebih dekat berbobot lebih besar. distance biasanya lebih baik.
algorithm
auto memilih otomatis. ball_tree atau kd_tree lebih efisien untuk dataset besar dimensi rendah. brute untuk dimensi sangat tinggi atau dataset kecil.

Implementasi Scikit-learn

from sklearn.neighbors import KNeighborsClassifier
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline
from sklearn.model_selection import GridSearchCV

# PENTING: selalu scaling sebelum k-NN
knn_pipeline = Pipeline([
    ('scaler', StandardScaler()),
    ('knn', KNeighborsClassifier())
])

# Cari nilai k terbaik dengan GridSearchCV
param_grid = {
    'knn__n_neighbors': [3, 5, 7, 9, 11, 15, 21],
    'knn__weights': ['uniform', 'distance'],
    'knn__metric': ['euclidean', 'manhattan']
}
grid_search = GridSearchCV(knn_pipeline, param_grid, cv=5, scoring='f1_macro')
grid_search.fit(X_train, y_train)

print(f"Best params: {grid_search.best_params_}")
print(f"Best CV score: {grid_search.best_score_:.3f}")
print(f"Test score: {grid_search.score(X_test, y_test):.3f}")

6. Support Vector Machine (SVM)

06 / 06
Support Vector Machine
sklearn.svm.SVC · SVR
Algoritma yang mencari hyperplane optimal yang memisahkan kelas dengan margin terlebar. Dapat menangani pola non-linier melalui teknik kernel trick — memproyeksikan data ke dimensi lebih tinggi tanpa komputasi eksplisit. Secara teoritis sangat kuat.
Klasifikasi Regresi Kernel Trick High Dimension

Cara Kerja: Maximum Margin Classifier

SVM bekerja dengan mencari hyperplane (garis di 2D, bidang di 3D, dst.) yang:

  1. Memisahkan semua kelas dengan benar
  2. Memaksimalkan margin — jarak antara hyperplane dan titik data terdekat dari masing-masing kelas

Titik data yang berada tepat di batas margin disebut support vectors — hanya titik-titik inilah yang menentukan posisi hyperplane. Karena itu model tidak terpengaruh oleh titik data yang jauh dari batas keputusan.

Visualisasi — SVM: Hyperplane & Margin
Margin →
Hyperplane
Support vectors (dengan lingkaran) menentukan posisi margin. Titik-titik lain tidak mempengaruhi hyperplane.

Kernel Trick: Menangani Data Non-Linier

Jika data tidak bisa dipisahkan secara linier, SVM menggunakan kernel function yang secara implisit memetakan data ke dimensi yang lebih tinggi di mana pemisahan linier menjadi mungkin.

LINEAR
Garis/bidang lurus. Gunakan saat data linearly separable atau dimensi sangat tinggi (teks).
RBF (Radial Basis)
Default dan paling serbaguna. Bisa menangkap batas keputusan yang sangat non-linier.
POLYNOMIAL
Untuk data dengan hubungan polinomial. Lebih lambat dari RBF, jarang menjadi pilihan pertama.
Kelebihan
  • Sangat efektif di dimensi tinggi (teks, genomik)
  • Tahan terhadap overfitting di dimensi tinggi
  • Kernel trick memberikan fleksibilitas non-linier
  • Prediksi hanya bergantung pada support vectors
Kekurangan
  • Sangat lambat pada dataset besar (O(n²) atau O(n³))
  • Tidak memberikan probabilitas langsung (butuh probability=True)
  • Sensitif terhadap pilihan hyperparameter C dan gamma
  • Tidak interpretable sama sekali

Hyperparameter Penting

C
Regularization parameter. C kecil → margin lebih lebar, lebih toleran terhadap misklasifikasi (soft margin). C besar → margin lebih sempit, berusaha mengklasifikasikan semua titik dengan benar (bisa overfit).
kernel
rbf (default) untuk kebanyakan kasus. linear untuk data berdimensi sangat tinggi (lebih cepat). poly jarang digunakan.
gamma (RBF)
Mengontrol "jangkauan pengaruh" setiap support vector. Gamma besar → setiap titik hanya mempengaruhi area kecil (bisa overfit). Gamma kecil → pengaruh lebih luas (bisa underfit). Default: scale = 1/(n_features × var(X)).

Implementasi Scikit-learn

from sklearn.svm import SVC
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline
from sklearn.model_selection import GridSearchCV

# SVM wajib di-scale terlebih dahulu
svm_pipeline = Pipeline([
    ('scaler', StandardScaler()),
    ('svm', SVC(kernel='rbf', probability=True, random_state=42))
])

# Grid search untuk C dan gamma — wajib di-tune
param_grid = {
    'svm__C':     [0.1, 1, 10, 100],
    'svm__gamma': ['scale', 'auto', 0.001, 0.01]
}
grid_search = GridSearchCV(svm_pipeline, param_grid, cv=5,
                            scoring='f1_macro', n_jobs=-1)
grid_search.fit(X_train, y_train)

print(f"Best: C={grid_search.best_params_['svm__C']}, gamma={grid_search.best_params_['svm__gamma']}")
print(f"Test score: {grid_search.score(X_test, y_test):.3f}")

# Probabilitas per kelas (butuh probability=True saat inisialisasi)
proba = grid_search.predict_proba(X_test[:5])
print("Probabilitas 5 sampel pertama:", proba)
📝

Kapan menggunakan SVM: Ideal untuk klasifikasi teks (TF-IDF menghasilkan dimensi sangat tinggi) dan data berdimensi tinggi lainnya seperti citra setelah ekstraksi fitur. Untuk dataset besar (>50k sampel), pertimbangkan LinearSVC yang jauh lebih cepat, atau gunakan Random Forest/XGBoost sebagai alternatif.

Perbandingan & Panduan Memilih

Tabel ringkasan untuk membantu memilih algoritma yang tepat berdasarkan kebutuhan proyek:

Algoritma Akurasi Kecepatan Train Kecepatan Prediksi Interpretable Perlu Scaling Terbaik Untuk
Linear/Logistic Reg ✓ Sangat Ya Baseline, hubungan linier, butuh interpretasi
Decision Tree ✓ Sangat Tidak Perlu penjelasan aturan, data kategorik
Random Forest Cukup Tidak Tabular data, produksi, performa cepat
Gradient Boosting Cukup Tidak Kompetisi, tabular data, akurasi maksimum
k-NN ✓ Ya, wajib Dataset kecil, prototipe, rekomendasi
SVM ✗ Ya, wajib Teks, dimensi tinggi, dataset <50k sampel

Alur Keputusan Cepat

🗺️
  1. Mulai selalu dari Logistic/Linear Regression sebagai baseline — jika cukup, selesai
  2. Jika perlu lebih baik dan interpretabilitas penting → Decision Tree (dengan pruning)
  3. Jika perlu lebih baik tanpa interpretabilitas → Random Forest (mudah, tahan overfit)
  4. Jika butuh akurasi maksimum dan mau tuning → XGBoost / LightGBM
  5. Jika data teks atau berdimensi tinggi → SVM (linear kernel) atau Logistic Regression
  6. Jika dataset sangat kecil atau butuh prototyping cepat → k-NN

}

for name, model in models.items():
