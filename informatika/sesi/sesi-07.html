Review &
Persiapan UTS

Rekap komprehensif P-01 s/d P-06 — dari konsep AI dasar, Machine Learning, sampai Deep Learning. Latihan soal pilihan ganda, esai studi kasus, dan kisi-kisi resmi UTS.

Review 100 menit CPMK: C1–C5 UTS setelah sesi ini

Tujuan Sesi Review

Sesi ini bukan materi baru — melainkan latihan aktif mengintegrasikan semua konsep yang telah dipelajari. Setelah sesi ini, mahasiswa diharapkan mampu:

  1. Menjelaskan perbedaan AI, Machine Learning, dan Deep Learning beserta contoh kasus nyata
  2. Memilih algoritma ML yang tepat berdasarkan karakteristik masalah dan data
  3. Menginterpretasikan metrik evaluasi model (accuracy, precision, recall, F1, RMSE) dalam konteks bisnis
  4. Mendeskripsikan arsitektur CNN dan pipeline NLP dari preprocessing hingga inferensi
  5. Menjawab soal studi kasus: diberikan skenario bisnis, merancang solusi AI yang sesuai
📝

UTS berlangsung setelah pertemuan ini. Format: 25 soal pilihan ganda (50 poin) + 3 soal esai studi kasus (50 poin). Durasi 90 menit. Open book tidak diizinkan. Kisi-kisi lengkap ada di bagian bawah halaman ini.

1. Rekap Cepat P-01 s/d P-06

Gunakan kartu di bawah ini sebagai cheatsheet terakhir sebelum UTS. Setiap kartu merangkum poin-poin yang paling sering keluar di soal ujian.

P-01 · Teori

Pengantar AI & Lanskap Industri

  • AI ⊃ ML ⊃ Deep Learning (hubungan subset)
  • Narrow AI vs General AI vs Super AI
  • Sejarah: Turing Test (1950), AI Winter, DL boom (2012)
  • 4 tipe AI: reactive, limited memory, theory of mind, self-aware
  • Dampak industri: otomasi, augmentasi, transformasi model bisnis
  • McKinsey: 70% perusahaan global sudah mengadopsi AI (2024)
P-02 · Teori

ML — Konsep & Algoritma

  • Supervised: ada label, tujuan prediksi → klasifikasi/regresi
  • Unsupervised: tanpa label, tujuan eksplorasi → klaster/reduksi dimensi
  • Reinforcement: agent, reward, environment
  • Bias-variance tradeoff: underfitting vs overfitting
  • Regularisasi: L1 (Lasso), L2 (Ridge)
  • Cross-validation: teknik evaluasi yang tidak bias
  • Algoritma kunci: Decision Tree, Random Forest, SVM, k-NN, k-Means, PCA
P-03 · Praktik

Praktik ML dengan Python & Scikit-learn

  • Pipeline: load → EDA → preprocess → train → evaluate
  • Train/test split: train_test_split(X, y, test_size=0.2, stratify=y)
  • Scaling: StandardScaler (Z-score), MinMaxScaler
  • Klasifikasi: LogisticRegression, RandomForestClassifier
  • Regresi: LinearRegression, GradientBoostingRegressor
  • Metrik: accuracy, precision, recall, F1-score, RMSE, R²
  • Churn prediction: fitur RFM (Recency, Frequency, Monetary)
P-04 · Praktik

AI untuk Bisnis & Deployment

  • Studi kasus: prediksi churn, harga properti, fraud detection
  • Deployment: model → pickle/joblib → REST API → Streamlit app
  • Streamlit: st.text_input(), st.button(), st.write()
  • Feature importance: identifikasi fitur paling berpengaruh
  • Model monitoring: drift detection setelah produksi
  • ROI AI: nilai bisnis harus terukur, bukan sekadar akurasi model
P-05 · Teori

Deep Learning & Neural Network

  • Neuron → Layer → Network; aktivasi: ReLU, Sigmoid, Softmax
  • Forward pass: prediksi; backward pass: update bobot via gradient descent
  • Loss: MSE (regresi), Cross-entropy (klasifikasi)
  • Optimizer: Adam, SGD, RMSprop
  • Dropout: regularisasi dengan mematikan neuron sementara
  • Batch size & epoch: trade-off kecepatan vs stabilitas
  • CNN: Conv2D → MaxPool → Flatten → Dense; kuat untuk gambar
  • RNN/LSTM: untuk data sekuensial (teks, time series)
P-06 · Praktik

Praktik Deep Learning: CNN & Sentimen

  • MNIST: (N,28,28,1), normalisasi /255, label 0–9
  • CNN lebih baik dari MLP untuk gambar karena mempertahankan struktur spasial
  • NLP pipeline: cleaning → tokenize → pad_sequences → embedding
  • Tokenizer: fit hanya pada train data (hindari data leakage)
  • Model sentimen: Embedding → GAP/LSTM → Dense(sigmoid)
  • Dataset imbalanced: F1-score lebih penting dari accuracy
  • Confusion matrix: TP, FP, TN, FN

2. Latihan Soal Pilihan Ganda

Klik opsi untuk memeriksa jawaban. Penjelasan akan muncul setelah memilih. Latihan ini mencerminkan format dan tingkat kesulitan UTS.

No. 1 Manakah pernyataan yang paling tepat menggambarkan hubungan antara AI, Machine Learning, dan Deep Learning?
AMachine Learning adalah superset dari AI, dan Deep Learning adalah bagian dari Machine Learning
BAI adalah superset, Machine Learning adalah subset AI, dan Deep Learning adalah subset Machine Learning
CKetiganya adalah istilah yang berbeda untuk teknologi yang sama
DDeep Learning dan Machine Learning adalah dua cabang AI yang sejajar, tidak berhubungan hierarkis
Jawaban: B. AI adalah bidang paling luas (membuat mesin "cerdas"). Machine Learning adalah subset AI yang belajar dari data tanpa diprogram eksplisit. Deep Learning adalah subset ML yang menggunakan jaringan syaraf buatan berlapis banyak. Representasi yang benar: AI ⊃ ML ⊃ DL.
No. 2 Sebuah model Random Forest dilatih pada data training dengan accuracy 98%, tetapi saat diuji pada data test hasilnya hanya 72%. Fenomena ini disebut apa, dan solusinya adalah?
AUnderfitting; solusinya menambah jumlah fitur dan epoch training
BData imbalance; solusinya menggunakan SMOTE untuk oversampling kelas minoritas
COverfitting; solusinya regularisasi, pruning pohon, menambah data, atau cross-validation
DData leakage; solusinya memisahkan test set sebelum preprocessing apapun
Jawaban: C. Gap besar antara train accuracy (tinggi) dan test accuracy (rendah) adalah tanda khas overfitting — model menghafal data training, bukan mempelajari pola umum. Solusi: regularisasi (max_depth, min_samples_leaf pada Random Forest), lebih banyak data training, atau cross-validation untuk memilih hyperparameter yang lebih general.
No. 3 Sebuah sistem deteksi penipuan (fraud detection) menghasilkan: Precision = 0.95, Recall = 0.60. Dalam konteks ini, apa implikasi bisnis dari nilai Recall yang rendah?
A40% transaksi penipuan nyata tidak terdeteksi (lolos sebagai transaksi normal) — kerugian finansial langsung
B5% prediksi "fraud" yang diblokir ternyata adalah transaksi sah — mengganggu pelanggan
CModel terlalu sensitif dan memblokir terlalu banyak transaksi
DDataset tidak seimbang sehingga model tidak dapat dipercaya
Jawaban: A. Recall = TP / (TP + FN). Recall 0.60 artinya dari semua fraud yang sebenarnya ada, hanya 60% yang berhasil ditangkap — 40% sisanya lolos (False Negative). Untuk fraud detection, False Negative sangat berbahaya karena berarti kerugian finansial nyata. Precision yang tinggi (0.95) hanya berarti ketika model bilang "fraud", hampir selalu benar — tapi ini tidak membantu kalau banyak fraud yang tidak terdeteksi sama sekali.
No. 4 Mengapa Conv2D pada CNN menghasilkan performa lebih baik dari Dense layer biasa untuk klasifikasi gambar?
AConv2D menggunakan lebih banyak parameter sehingga kapasitas modelnya lebih tinggi
BConv2D menghasilkan gambar resolusi lebih tinggi untuk input model
CConv2D menghilangkan kebutuhan normalisasi data gambar
DConv2D mempertahankan hubungan spasial piksel dan bersifat translation-invariant — pola terdeteksi di mana pun letaknya
Jawaban: D. Dense layer "meratakan" gambar menjadi vektor 1D — menghancurkan semua informasi posisi relatif piksel. Conv2D menggunakan filter yang bergeser di seluruh gambar (sliding window), sehingga bisa mendeteksi pola (tepi, tekstur) di posisi mana pun. Ini juga parameter-efficient: filter 3×3 dengan 32 output memiliki jauh lebih sedikit parameter daripada Dense yang setara, sekaligus lebih kuat untuk gambar.
No. 5 Dalam pipeline NLP, mengapa Tokenizer harus di-fit hanya pada data training, bukan pada seluruh dataset?
AKarena data test biasanya lebih besar, sehingga tidak praktis untuk di-fit
BUntuk mencegah data leakage — kosakata test set tidak boleh "bocor" ke proses training
CKarena Keras Tokenizer tidak mendukung fit pada seluruh dataset
DUntuk mempercepat proses training dengan vocabulary yang lebih kecil
Jawaban: B. Ini adalah prinsip data leakage prevention. Jika Tokenizer di-fit pada seluruh data (train + test), maka informasi dari test set (frekuensi kata, kosakata) sudah "diketahui" model saat training — memberikan keunggulan yang tidak akan ada di produksi nyata. Evaluasi jadi terlalu optimis. Dalam produksi, model akan menemukan kata-kata baru yang tidak ada di training — ini disimulasikan dengan token <OOV>.
No. 6 Sebuah dataset e-commerce memiliki 95% ulasan positif dan 5% ulasan negatif. Model yang selalu memprediksi "positif" akan mendapat accuracy berapa, dan apakah ini model yang baik?
AAccuracy 50%, dan ini tidak baik karena model tidak lebih baik dari random
BAccuracy 95%, dan ini adalah model yang sangat baik karena akurasi tinggi
CAccuracy 95%, tetapi model ini tidak berguna sama sekali — F1-score untuk kelas negatif adalah 0
DAccuracy 5%, karena model salah memprediksi semua ulasan negatif
Jawaban: C. Model yang selalu prediksi "positif" mendapat 95% accuracy karena 95% data memang positif — ini disebut majority class classifier atau dummy classifier. Tapi model ini sama sekali tidak berguna: Recall kelas negatif = 0 (tidak ada satupun negatif yang terdeteksi). F1-score untuk kelas negatif = 0. Untuk imbalanced dataset, gunakan F1-score per kelas, macro F1, atau AUC-ROC sebagai metrik evaluasi, bukan accuracy.
No. 7 Fungsi aktivasi apa yang paling tepat digunakan pada output layer untuk masalah klasifikasi multi-kelas (10 kelas), dan loss function apa yang sesuai?
ASoftmax + Sparse Categorical Cross-Entropy (jika label integer) atau Categorical Cross-Entropy (jika one-hot encoded)
BSigmoid + Binary Cross-Entropy, diterapkan pada setiap neuron output secara independen
CReLU + MSE karena menghasilkan output numerik yang mudah diinterpretasikan
DTanh + Hinge Loss karena lebih stabil untuk multi-kelas
Jawaban: A. Softmax memastikan semua output berjumlah 1.0 dan bisa diinterpretasikan sebagai probabilitas per kelas — wajib untuk multi-kelas mutual exclusive (setiap sampel hanya punya satu label). Sigmoid digunakan untuk klasifikasi biner atau multi-label (satu sampel bisa masuk beberapa kelas). Loss yang sesuai: sparse_categorical_crossentropy jika label berupa integer (0, 1, 2, ...), atau categorical_crossentropy jika label sudah one-hot encoded.
No. 8 Seorang data scientist ingin mengelompokkan 10.000 pelanggan berdasarkan perilaku pembelian tanpa mengetahui berapa kelompok yang ada sebelumnya. Algoritma mana yang PALING tepat?
ALogistic Regression dengan threshold berbeda untuk setiap kelompok
BK-Nearest Neighbors (k-NN) dengan k = jumlah kelompok yang diinginkan
CK-Means dengan k = 3 sebagai default industri untuk segmentasi pelanggan
DGunakan Elbow Method / Silhouette Score untuk menentukan k optimal, baru terapkan K-Means
Jawaban: D. K-Means membutuhkan k ditentukan di awal — tapi karena kita tidak tahu berapa kelompok yang "benar", kita perlu menentukan k secara empiris. Elbow Method: jalankan K-Means dengan berbagai nilai k (2–10), plot inertia (Within-Cluster Sum of Squares), cari "siku" di grafik. Silhouette Score: nilai mendekati 1 berarti klaster terpisah baik. Jawaban C salah karena mengasumsikan k=3 tanpa justifikasi dari data.

3. Latihan Soal Esai & Studi Kasus

UTS Blok 1 mencakup 3 soal esai studi kasus (masing-masing ~17 poin). Latihan berikut mencerminkan format dan tingkat kesulitannya. Kerjakan dulu sebelum melihat panduan jawaban.

💡

Struktur jawaban esai yang baik: (1) Identifikasi jenis masalah ML — klasifikasi/regresi/klaster/urutan. (2) Pilih algoritma + justifikasi berdasarkan karakteristik data. (3) Sebutkan fitur-fitur yang relevan. (4) Tentukan metrik evaluasi yang sesuai. (5) Antisipasi tantangan (imbalanced data, cold-start, dll).

Soal Esai 1 — Studi Kasus Bisnis
Sebuah platform streaming musik ingin memprediksi apakah pengguna akan berhenti berlangganan (churn) dalam 30 hari ke depan. Dataset yang tersedia: riwayat dengarkan (jumlah lagu, durasi, genre), data demografi (usia, kota), dan riwayat pembayaran (ketepatan bayar, histori upgrade/downgrade). Jelaskan: (a) ini masalah ML jenis apa, (b) algoritma apa yang Anda rekomendasikan beserta alasannya, (c) fitur-fitur mana yang kemungkinan paling prediktif, dan (d) metrik evaluasi apa yang paling relevan dan mengapa.
Panduan: masalah ini adalah klasifikasi biner. Pikirkan karakteristik datanya — tabular, label tersedia, skala ribuan pengguna. Ingat juga bahwa churn biasanya imbalanced (lebih banyak yang tidak churn). Apa implikasi ini terhadap pilihan metrik?
Soal Esai 2 — Desain Sistem
Sebuah toko online ingin membangun sistem yang secara otomatis mengklasifikasikan ribuan foto produk yang diunggah penjual ke dalam 20 kategori produk (elektronik, fashion, makanan, dll). Gambar bervariasi ukuran, latar belakang, dan kualitas. Jelaskan: (a) pendekatan Deep Learning mana yang paling tepat, (b) bagaimana preprocessing gambar yang diperlukan, (c) bagaimana menangani variasi kualitas foto yang ekstrem, dan (d) jika Anda hanya punya 500 foto berlabel per kategori, apa strategi yang direkomendasikan?
Panduan: ini jelas computer vision → CNN. Untuk jumlah data yang sedikit (500 per kelas = 10.000 total), pikirkan teknik yang dibahas di P-05 untuk mengatasi data terbatas. Preprocessing: resize ke ukuran seragam, normalisasi.
Soal Esai 3 — Interpretasi & Etika
Sebuah bank menggunakan model Machine Learning untuk menentukan apakah seseorang layak mendapat pinjaman. Model Random Forest menghasilkan accuracy 91% pada test set. (a) Apakah accuracy 91% sudah cukup untuk di-deploy? Jelaskan faktor lain yang harus dievaluasi. (b) Bagaimana cara menjelaskan keputusan model kepada pemohon yang ditolak? (c) Apa risiko etika dan hukum jika model memiliki bias terhadap kelompok demografis tertentu? (d) Bagaimana cara mendeteksi bias ini secara teknis?
Panduan: ini mencakup C5 (etika AI). Ingat materi tentang fairness, explainability (SHAP, LIME untuk Random Forest), dan implikasi regulasi. Untuk kredit/pinjaman, ada regulasi spesifik di banyak negara tentang fair lending.

5. Strategi & Tips Menghadapi UTS

Strategi Pilihan Ganda

✓ Eliminasi dulu jawaban yang jelas salah. Dari 4 opsi, biasanya 1-2 bisa langsung dicoret.
✓ Soal "mengapa CNN lebih baik", "kapan menggunakan F1 vs accuracy" — fokus pada alasan konseptual, bukan teknis.
✓ Waspada jawaban yang "hampir benar" — sering ada opsi yang sebagian besar benar tapi ada satu kata kunci yang salah.
✓ Alokasi waktu: ~1,5 menit per soal PG → 37 menit total untuk semua PG.

Strategi Soal Esai

✓ Baca soal 2x sebelum menjawab. Identifikasi: jenis masalah, karakteristik data, tujuan bisnis.
✓ Selalu justifikasi pilihan Anda. "Saya pilih Random Forest karena..." lebih baik dari sekadar menyebut nama algoritma.
✓ Sebutkan trade-off. Tidak ada algoritma yang sempurna — menunjukkan kesadaran akan limitasi menunjukkan pemahaman mendalam.
✓ Alokasi: ~17 menit/soal esai. Jika macet, tinggalkan dan kembali setelah PG selesai.
Konsep Kunci yang Wajib Hafal
Metrik Evaluasi
• Accuracy = (TP+TN) / Total
• Precision = TP / (TP+FP)
• Recall = TP / (TP+FN)
• F1 = 2×(P×R)/(P+R)
• RMSE = √(Σ(y−ŷ)² / n)
Kapan Pakai Apa
• Imbalanced → F1, AUC-ROC
• Balanced → Accuracy cukup
• Regression → RMSE, MAE, R²
• False negative mahal → max Recall
• False positive mahal → max Precision
